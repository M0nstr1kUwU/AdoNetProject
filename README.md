# Журнал студентов

Приложение на C# и WinForms в котором можно вести список студентов и быстро находить нужную запись по ФИО, почте или группе. Данные хранятся локально в SQLite, а запросы выполняются через ADO.NET

| Команда | Использование |
| --- | --- |
| Добавить студента | Заполнить ФИО, группу и курс (почта не обязательна) |
| Редактировать | Выбрать строку и нажать «Изменить» |
| Удалить запись | Выбрать студента, нажать «Удалить» и подтвердить действие |
| Найти студента | Введите часть ФИО или адреса |
| Выбрать группу | Выбор существующих групп |

## Запуск
Нужны Windows и [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
При первой сборке NuGet скачает пакет `Microsoft.Data.Sqlite`. А при первом запуске появится пустая база `%LOCALAPPDATA%\StudentRegistry\students.db`

## Как работает приложение:

- [`MainForm.cs`](src/StudentRegistry/MainForm.cs) показывает таблицу, управляет поиском и вызывает операции с записями
- [`StudentEditorForm.cs`](src/StudentRegistry/StudentEditorForm.cs) показывает карточку студента и проверяет ввод
- [`StudentRepository.cs`](src/StudentRegistry/StudentRepository.cs) открывает `SqliteConnection`, собирает `SqliteCommand` и передаёт введённые значения как параметры
- Для получения списка используется `ExecuteReader()`. Для добавления `ExecuteScalar()` возвращает ID новой записи. При изменении и удалении `ExecuteNonQuery()` возвращает количество затронутых строк
- После перезапуска приложения - данные сохранятся в students.db
